# CMM-004 Add UI Toolkit capability pack for UXML and USS

**Ready status:** Ready

**Team:** Atlas (advisor) · Prism (advisor) · Forge (lead) · Sentinel (reviewer)

## Goal

- Add dedicated UI Toolkit inspect, apply, validate, and playtest tools.
- Preserve the existing uGUI tool behavior.

## Core requirements

- Integrate through the existing command manifest, Node bridge, and `MCPHandlers.Dispatch`.
- Keep inspect and validate read-only and bounded.
- Protect apply with plan/commit, `expectedHash`, write gate, atomic writes, and rollback.
- Return useful observable evidence from playtest without hiding unsupported runtime conditions.
- Add contract and Editor tests, and keep repository content English-only.

## Initial status

- No `unity_uitk_*` tools or `UnityEngine.UIElements` implementation currently exists.
- Current UI commands target uGUI and must remain unchanged.
