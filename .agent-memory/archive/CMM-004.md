# CMM-004 Add UI Toolkit capability pack for UXML and USS

**Status:** Complete

**Team:** Atlas (advisor) · Prism (advisor) · Forge (lead) · Sentinel (reviewer)

## Goal

- Add dedicated UI Toolkit inspect, apply, validate, and playtest tools.
- Preserve the existing uGUI tool behavior.

## Core requirements

- Integrate through the existing command manifest, Node bridge, and `MCPHandlers.Dispatch`.
- Keep inspect and validate read-only and bounded.
- Protect apply with plan/commit, `expectedHash`, write gate, atomic writes, and rollback.
- Return useful observable evidence from playtest without hiding unsupported runtime conditions.
- Add contract and Editor tests, and keep repository content English-only.

## Initial status

- No `unity_uitk_*` tools or `UnityEngine.UIElements` implementation currently exists.
- Current UI commands target uGUI and must remain unchanged.

## Implementation

- Added `unity_uitk_inspect`, `unity_uitk_validate`, `unity_uitk_apply`, and `unity_uitk_playtest` across the command manifest, Node bridge, dispatcher, and Editor handlers.
- Added bounded UXML/USS source inspection and heuristic validation.
- Added request-aware fail-closed write classification for mixed read/write routes.
- Added stateless plan/commit editing with deterministic hashes, stale-source rejection, per-file atomic replacement, and full-request rollback.
- Added bounded live `UIDocument` playtest runs with state, console/exception, and screenshot evidence.
- Preserved existing uGUI tools and compatibility identifiers.

## Verification

- Node/MCP tests passed: 17/17.
- Unity 6 production and Editor-test static compilation passed.
- Added 17 adversarial NUnit cases and a real MCP image-response integration test.
- JSON, JavaScript syntax, English-only, forbidden-brand, and diff checks passed.
- Forge fixed the only confirmed implementation defect: CS0173 in the playtest document candidate selection.

## Watch

- Runtime `AssetDatabase.Refresh` rollback and live `UIDocument` lifecycle are compile-covered and test-authored but were not executed inside Unity.
