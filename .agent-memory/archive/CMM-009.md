# CMM-009 Harden presence heartbeat and clarify MCP activity logging

**Status:** Done

**Team:** Forge (lead) · Sentinel (reviewer)

## Root cause

- The presence heartbeat ran every two seconds and used `File.Replace` for atomic updates.
- A transient Windows reader or antivirus lock could make replacement fail with `Unable to remove the file to be replaced` even though the directory was writable.
- Every heartbeat failure emitted a warning, which flooded the Unity Console.
- The inbound activity view showed only custom TCP dispatcher traffic, while official Unity MCP used a separate Named Pipe transport; the UI did not explain this boundary clearly.

## Resolution

- Retried transient presence replacement failures three times with bounded delays and preserved temporary-file cleanup.
- Throttled repeated presence warnings to once per directory every 30 seconds.
- Added a thread-safe log revision and tab-scoped repaint for incoming custom TCP activity.
- Clarified the custom TCP and official Named Pipe transport boundary in the Editor UI and documentation.
- Released the implementation metadata and changelog as version 2.0.2.
